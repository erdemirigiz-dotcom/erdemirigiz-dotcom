## Iron Vision Tools

Practical AI tools for small businesses. Independent, self-funded, based in Edirne, Türkiye.
Everything is built and shipped by one person, Demir, working with terminal AI coding agents.

**Website:** [ironvisiontools.com](https://ironvisiontools.com)

### What we build

- **AIrandevu** — a WhatsApp appointment bot for barbers and hair salons. Customers book by
  sending a message; no app to install, bookings land in the shop's own calendar. In pilot.
- **Website showcase** — a small factory for fast, static business sites (hotels, glamping,
  workshops, photographers). 11 live demo sites: [ironvisiontools.com/vitrin/vitrin-hub](https://ironvisiontools.com/vitrin/vitrin-hub/)
- **AgentOS** — the automation system that runs the company: task board, watchdogs,
  scheduled jobs, backups. Also installed for businesses as a tailored service.
- **Voice Chief** — a voice interface for terminal-based AI agents; speak to the agent,
  hear the answer back. Works with Claude Code, ChatGPT, and Codex sessions.
- **StonkLab** — digital products and tools for traders and hobbyists.

### How we work

Small, boring, and real: static sites over frameworks, plain scripts over platforms,
one machine instead of a stack. If a tool cannot be explained to the shop owner using it,
it is not finished.
